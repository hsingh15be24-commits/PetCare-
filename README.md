# Pet Care Management System

A full-stack web application designed to simplify pet care services by connecting pet owners, caretakers, and veterinarians on a single platform.

---

## Overview

The **Pet Care Management System** is built to help pet owners manage their pets efficiently while providing access to trusted caretakers and veterinary services.

This platform enables users to book pet boarding, monitor pet health, manage appointments, and handle payments in a structured and user-friendly way.

---

## Features

### User Roles

* **Pet Owner**
* **Caretaker**
* **Veterinarian**
* **Admin**

Each role has a dedicated dashboard with specific functionalities.

---

### Pet Owner

* Create and manage profile
* Add multiple pets
* Store pet details (age, breed, medical history, diet, etc.)
* Book pet boarding services
* Select service plans
* Track pet health updates
* View assigned caretaker
* View payment history

---

### Caretaker

* View assigned pets
* Update feeding and activity logs
* Upload pet images
* Add daily notes and observations

---

### Veterinarian

* Access pet medical history
* Add prescriptions
* Update vaccination records
* Schedule checkups
* Upload health reports

---

### Admin Panel

* Manage users (owners, caretakers, vets)
* Manage bookings and appointments
* Approve caretakers
* Monitor payments
* View analytics and reports

## Installation

1. Clone the repository:

```
git clone https://github.com/your-username/pet-care-management-system.git
```

2. Navigate to project folder:

```
cd pet-care-management-system
```

3. Install dependencies:

```
npm install
```

4. Set up environment variables:

```
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
```

5. Run the project:

```
npm run dev
```
